# Bit-boundary labeling: invented_robot-set
#
# A bit = the smallest unit that works ON ITS OWN without earlier setup (premise + its tags).
# Consecutive bits on the same topic form a THREAD: mark the later ones with >>> continues.
# A callback returns to an earlier bit AFTER other material; it starts a NEW bit.
# Crowd-work exchanges are their own bit.
#
# HOW: put a line with only >>> directly ABOVE the first line of each new bit.
#      Optional note after it, e.g.  >>> the dentist
#      SAME TOPIC as the previous bit:  >>> continues: the dentist
#      BOTH (same topic + calls back):   >>> continues callback 0042: the dentist
#      CALLBACK: on the LATER bit, name the line where the earlier bit starts:
#          >>> callback 0042: the dentist
#      (a callback bit starts where its SETUP starts, not at the payoff line)
#      LINE CALLBACK: one line inside an ordinary bit that refers back; put directly above it:
#          @callback 0189: the front door      (number = the earlier line it refers to)
#      Test: delete the reference; is the stretch still a bit? yes -> @callback, no -> >>> callback
#      The first line of the set is always a bit start; no need to mark it.
#      ⟨L2⟩ etc. show the laugh that followed a line (context only, don't edit them).
#      Don't edit or reorder the [NNNN] lines. Save, then run:
#          python -m pipeline.labels import invented_robot-set
#
